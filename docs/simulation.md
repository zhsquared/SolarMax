# Simulation

SolarMax has **three** simulators. All run the real control brain
(`lib/tracker_core` + `lib/solar_math`) — only the hardware is faked.

| | Native auto-runner | Interactive terminal (FTXUI) | 3D window (raylib) |
|--|-------------------|------------------------------|--------------------|
| Build | `pio run -e simulate` | `cd sim && cmake …` | `cd sim3d && cmake …` |
| Run | `.pio/build/simulate/program` | `./build/solarmax_sim` | `./build/solarmax_sim3d` |
| Style | Prints a full day, scrolls | Live TUI (side view **or** 3D wireframe dome) | Real 3D sky dome |
| Controls | none (auto) | scrub time, wind, roof angle, presets, `v` view | + mouse orbit / zoom |
| Best for | quick "does it work" check | live exploring in a terminal | **presentations / proving correctness** |

## How the fake hardware works
The firmware never touches pins directly — it calls functions like
`getCurrentTimeUTC()`, `readWindSpeedMPH()`, and `driveToAngle()`. In a simulation
build those names resolve to **fake implementations** instead of the real drivers.
The control logic can't tell the difference.

Each fake value comes from a tiny model:
- **Time** — the computer's real clock, scaled up (e.g. 120×), added to a start date.
- **Sun** — *not faked.* The real NOAA math is fed the fake clock, so the sun is genuine physics on a sped-up day.
- **Panel angle** — a single variable the fake motor stores/returns (a perfect motor).
- **Wind** — a scripted value (native runner) or a slider you control (FTXUI).
- **Limit switches / LDRs** — derived from the panel angle / constant.

## Native auto-runner (`simulate`)
Starts just before sunrise on the summer solstice and plays a full day at 120×
(~12 real minutes). Prints the boot self-check, then sun position, motor moves, and
state changes (tracking → wind-stow → night). Good for a fast confidence check.

```bash
pio run -e simulate && .pio/build/simulate/program   # Ctrl+C to stop
```

## Interactive simulator (`sim/`)
A terminal UI (FTXUI) with a live side-view of the sun vs. the panel, the current
state, sun angles, wind, and roof settings — all controllable from the keyboard.

```bash
cd sim
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release   # first time: downloads FTXUI
cmake --build build -j4
./build/solarmax_sim
```

Controls and what to look for are in [../sim/README.md](../sim/README.md). Highlights:
- `v` switches between the flat **side view** and a rotatable **3D wireframe dome**.
- `1`–`4` jump to summer/winter solstice, equinox, sunrise; `0` jumps to the
  **equator demo** to check tracking against known sun angles.
- `-` / `=` change wind to trigger and clear **STOW**.
- `[` `]` / `<` `>` change **roof tilt / azimuth** and watch tracking adjust.

## 3D sky-dome window (`sim3d/`)
A real 3D view (raylib) of the sun on the sky dome and the panel tracking it,
built to **demonstrate correctness**. It defaults to the **equator**, where the
sun paths match the textbook diagram (`sun_paths.jpg`) exactly, and a **Verify**
panel lights up green when the live sun lands on a known position (zenith at
equinox noon, ±23.5° at the solstices, due-east at sunrise).

```bash
cd sim3d
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release   # first time: downloads raylib
cmake --build build -j4
./build/solarmax_sim3d
```

Drag to orbit, scroll to zoom; the keys mirror the terminal sim. Full details in
[../sim3d/README.md](../sim3d/README.md).

## Shared geometry
Both interactive views get their 3D geometry from one place, `sim/sky_scene.h`
(sun vector, panel normal, and sun-path arcs generated by calling the real
`calculateSolarPositionRaw`), and one portable clock, `sim/simclock.h`. So the
terminal wireframe and the raylib window are guaranteed to show the same thing —
and both show what the firmware actually computes.

## Why three?
The native runner is the zero-setup smoke test. The terminal simulator is the
lightweight live tool that runs anywhere over SSH. The 3D window is the
presentation piece — it makes "the tracking code is correct" something a viewer
can confirm by eye against known sun positions.
